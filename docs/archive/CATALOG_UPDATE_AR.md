# تحديث البحث وفلاتر المتجر

تحديث واجهة مبني على نسخة RIVO متعددة العملات مع Payunit وصفحة تفاصيل الطلب السابقة. خذ نسخة احتياطية من الملفات المطابقة قبل الاستبدال، وادمج أي تعديلات أحدث أجريتها محليًا.

انسخ public وtests من الحزمة إلى مجلد rivo-cloudflare بنفس المسارات. ملفات الواجهة الأربعة تعمل معًا: index.html وapp.js وcatalog.js وcatalog.css. لا تنس الملفات الجديدة.

```powershell
npm test
npm run deploy
```

لا توجد ترحيلات أو مفاتيح جديدة، ولا تستبدل wrangler.json. بعد النشر استخدم Ctrl+F5.

## المميزات

- البحث بعدة كلمات في الاسم والوصف والفئة والمنطقة؛ يتجاهل التشكيل والتطويل واختلافات الألف وحالة الأحرف الإنجليزية. لا يترجم أسماء الألعاب بين اللغات.
- الفئات الموجودة سابقًا مع فلتر منطقة التفعيل من بيانات المنتجات، وحدود سعر حسب عملة العرض، وترتيب السعر أو الاسم.
- خيار المتاح للطلب فقط، وشارة توضح التوفر أو عدم توفر وسيلة الدفع.
- زر مسح الفلاتر وعدد النتائج ورسالة حدود السعر غير الصحيحة.
- منع متابعة سلة تحتوي منتجًا غير متاح، مع بيان المنتج الذي يحتاج حذفه.
- مسح حدود السعر عند تغيير العملة ومنع متابعة الطلب أثناء تحميل أسعار العملة الجديدة.

منطقة تفعيل البطاقة مستقلة عن دولة الزبون وعملة العرض. المنتجات التي بلا منطقة تظهر عند اختيار «كل المناطق» فقط. التوفر المعروض يستند لبيانات المتجر الحالية؛ يعيد الخادم التحقق عند إنشاء الطلب.

## تجربة بعد النشر

جرّب البحث باسم منتج، ثم جمع الفئة والمنطقة وحدود السعر. جرّب حالة بلا نتائج ومسح الفلاتر. بدّل العملة وتأكد من مسح حدود السعر وتغيّر الأسعار. افتح منتجًا غير متاح وتأكد من تعطيل الإضافة. اختبر من الموبايل أيضًا.

حزمة التحديث لا تشمل صور المتجر أو الشعار؛ تبقى الأصول الموجودة عندك. لم تُغيّر معالجة الدفع أو مشكلة الرجوع من Payunit. لم تُنفّذ معاينة بمتصفح هنا لعدم توفر متصفح الاختبار.
