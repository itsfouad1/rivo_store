## ما حُذف فعلًا

- `wrangler.before-rivo-ai.json`: نسخة إعدادات قديمة كان يولدها سكربت إضافة AI، وليست ملف الإعداد النشط.
- `wrangler.json.backup-1792673310091`: نسخة إعدادات احتياطية قديمة وليست ملف الإعداد النشط.
- `START_HERE_AR.txt`: تعليمات نسخ حزمة Auth القديمة؛ استبدلها README الحالي، مع حفظ التفاصيل في الأرشيف.

لم نحذف اختبارات أو ترحيلات أو أدوات إعداد أو كود ميزة قائمة لمجرد أن الملف قديم. تغييرات `.gitignore` تمنع إدراج النسخ الاحتياطية المستقبلية ونواتج البناء والقيم المحلية الخاصة. حذف الملفات من نسخة العمل لا يمحوها من تاريخ Git.

## تطبيق التنظيم على مجلدك الحالي — الطريقة المقترحة

الحزمة تتضمن نسخة المشروع كاملة وملف `RIVO_Organization.patch`. **نسخ المجلدات فوق القديمة فقط لا ينفذ الحذف أو النقل بالكامل**، لذلك استخدم الـpatch داخل مستودعك الحالي حتى يبقى تاريخ Git وإعداداتك المحلية.

1. تأكد أن مجلدك يحتوي آخر تحديث رفعته، وأن `git status` نظيف. احفظ أي شغل محلي قبل التطبيق؛ لا تستخدم reset أو clean لحذفه.
2. انسخ `RIVO_Organization.patch` من الحزمة إلى جذر مشروعك، بجانب `package.json`.
3. افتح PowerShell في مجلد المشروع ونفّذ كتلة الأوامر التالية كما هي. الفحص الأول لا يغير الملفات، ويتوقف عند أي تعارض بدل الكتابة فوق نسخة مختلفة.

```powershell
& {
  git apply --check RIVO_Organization.patch
  if ($LASTEXITCODE -ne 0) { throw "Patch does not match your files. Stop and review the conflict." }
  git apply RIVO_Organization.patch
  if ($LASTEXITCODE -ne 0) { throw "Patch failed" }
  npm run check
  if ($LASTEXITCODE -ne 0) { throw "Path check failed" }
  npm test
  if ($LASTEXITCODE -ne 0) { throw "Tests failed" }
  npm run build
  if ($LASTEXITCODE -ne 0) { throw "Build failed" }
}
```

لم تتغير الاعتمادات، فلا يلزم تثبيتها من جديد إذا `node_modules` موجود. إذا غير موجود نفّذ `npm ci` أولًا. بعد نجاح التطبيق انقل ملف الـpatch خارج المشروع أو احذفه حتى لا ترفعه كملف مصدر، ثم راجع `git status` و`git diff --stat` قبل الكوميت.

ملفات `.dev.vars` و`.env` و`node_modules` والنسخ الخاصة غير المرفوعة إلى Git لا تشملها الرقعة. تبقى أسرار Cloudflare المسجلة على حسابك خارج هذه الملفات أيضًا. إذا ملف الإعداد عندك مختلف محليًا، فحص الرقعة قد يرفض تطبيقه؛ لا تستبدل إعدادات حسابك بنسخة قديمة لتجاوز الخطأ.

بديلًا عن الـpatch، تستطيع استخراج `rivo-cloudflare/` في **مجلد جديد** ومراجعته، ثم نقل إعداداتك المحلية الخاصة إليه. هذه نسخة كاملة وليست حزمة ملفات جديدة فقط. لا تحذف المجلد القديم قبل التأكد من حفظ شغلك وتاريخ Git فيه.

## الفحص والنشر

- قبل التنظيم: 160 اختبارًا ناجحًا.
- بعد التنظيم: 160 اختبارًا ناجحًا.
- فحص الاستيرادات والمسارات المحلية: ناجح.
- تجميع Wrangler باستخدام dry-run: ناجح، لا ينشر على الحساب.
- ترحيلات D1 القديمة: محفوظة بالبايت دون تعديل، وتطبيقها نجح على قاعدة محلية فارغة.
- تحميل HTTP محلي عبر Wrangler: نجحت 12 صفحة و40 ملف JavaScript/CSS وثلاث صور/أيقونات، مع تطابق محتوى الأصول مع الملفات.
- تتبع الاستيرادات من Worker وصفحات HTML لم يُظهر ملفات تشغيل منفصلة غير مستخدمة؛ لم نحذف كودًا قائمًا بلا دليل.
- لم تُنفذ مراجعة مرئية جديدة بالمتصفح؛ الفحص هنا لتحميل الملفات والمسارات والسلوك المغطى بالاختبارات.

اختبارات الطلبات والخدمات تستخدم المحاكاة؛ لم تُنفذ معاملات دفع أو إرسال بريد أو طلب شراء من المورد. البريد وتجربة الدفع الحقيقي ما زالا مؤجّلين. لا نغيّر تصميم الصفحات أو سلوك الميزات ضمن مهمة التنظيم.

عند جاهزيتك لنشر التنظيم نفّذ `npm run deploy` بنفسك؛ بعدها Ctrl+F5 لتحميل روابط JavaScript وCSS الجديدة. لا يحتاج هذا التنظيم وحده إلى `db:remote`. إذا لم تكن طبقت ترحيل 0016 للميزات السابقة، فهو ما زال مطلوبًا لها، ولا يغني نقل الملفات عنه.
