# RIVO — النسخة المستقلة لـ Cloudflare

هذه نسخة كاملة من المتجر ولوحتي الإدارة والزبون، بهوية RIVO البنفسجية والسماوية، مع تسجيل مستقل بالإيميل وكلمة مرور. تقبل Gmail وأي إيميل صحيح. هذا ليس زر الدخول بحساب Google، وكلمة المرور تخص ريفو وليس حساب Gmail.

## ما تم إنجازه

- تسجيل زبون جديد، دخول وخروج، تحويل تلقائي حسب صلاحية مخزنة بقاعدة البيانات.
- كلمات المرور مخزنة باستخدام PBKDF2-SHA256 مع salt عشوائي و600,000 دورة؛ جلسات عشوائية محفوظة كبصمات فقط، وكوكي HttpOnly / Secure / SameSite.
- صلاحية الأدمن لا تؤخذ من الإيميل ولا من بيانات يرسلها الزبون؛ تُمنح يدويًا من حساب Cloudflare.
- استرداد الحساب برمز عشوائي يُعرض مرة واحدة عند التسجيل؛ الاسترداد يبدله ويلغي الجلسات السابقة.
- ضبط محاولات الدخول والاسترداد، حماية Origin للعمليات التي تغيّر البيانات، تنظيف الجلسات المنتهية يوميًا.
- وظائف المنتجات والطلبات والموردين والإعدادات والصور محفوظة من النسخة السابقة.

## حدود واضحة قبل النشر

- النسخة **لم تُنشر على حسابك بعد**. رابط Sites القديم لم يتغير.
- قاعدة Cloudflare الجديدة تبدأ فارغة. هذا الملف لا يحتوي بيانات المتجر الحية أو صور R2 السابقة. إذا أضفت منتجات أو استقبلت طلبات بالفعل، يجب نقلها بشكل مستقل قبل الانتقال. حسابات ChatGPT القديمة لا تُربط تلقائيًا بمجرد تطابق الإيميل.
- لا يوجد تحقق من ملكية الإيميل أو إرسال رابط استعادة بالبريد بعد؛ الاسترداد يعمل بالرمز فقط. لا تمنح صلاحيات حساسة بناءً على إيميل غير متحقق.
- بوابة الدفع والمزامنة التلقائية مع الموردين غير مربوطتين. الطلب عبر واتساب متاح بعد إدخال الرقم والمنتجات.
- اشتقاق كلمات المرور يتطلب CPU مرتفعًا نسبيًا؛ الخطة المجانية محدودة بـ10ms CPU للطلب وقد تفشل معها عمليات الدخول. استخدم Workers Paid لتشغيل هذه النسخة بموثوقية، أو نربط مزود حسابات خارجي إذا أردت البقاء على المجاني. لم يتم تفعيل أو شراء أي خطة نيابة عنك.
- الصور تحتاج R2 مفعّلًا في الحساب. إذا لم ترد تفعيله الآن، احذف r2_buckets من wrangler.json واستخدم روابط صور HTTPS؛ رفع الملفات سيظل غير متاح.

## النشر من Windows / PowerShell

المتطلب: Node.js 22.12 أو أحدث. فك الضغط وافتح PowerShell داخل مجلد `rivo-cloudflare`.

### 1. تثبيت الأدوات وتسجيل الدخول

```powershell
npm install
npx wrangler login
npx wrangler whoami
```

سيفتح Cloudflare في المتصفح. سجّل الدخول وامنح Wrangler الصلاحيات بنفسك. لا ترسل كلمة المرور أو التوكن في المحادثة. إذا عندك أكثر من حساب، اختر الحساب الصحيح وأضف `account_id` إلى wrangler.json.

### 2. إنشاء قاعدة البيانات

```powershell
npx wrangler d1 create rivo-store-db
```

انسخ `database_id` الذي يرجع، وضعه مكان `REPLACE_WITH_YOUR_D1_DATABASE_ID` في `wrangler.json`. إذا كانت قاعدة بنفس الاسم موجودة، لا تحذفها؛ استخدم اسمًا جديدًا أو تأكد أنها قاعدة المتجر المقصودة قبل تطبيق الجداول.

### 3. صور المنتجات

إذا R2 مفعّل:

```powershell
npx wrangler r2 bucket create rivo-store-media
```

إذا الاسم موجود، تحقق أنه البكت المطلوب. أو احذف قسم `r2_buckets` كما هو موضح أعلاه لتبدأ بدون رفع صور.

### 4. اختبار ونشر

```powershell
npm test
npm run db:remote
npm run deploy
```

راجع أوامر الترحيل ثم وافق على تطبيقها في قاعدة المتجر الجديدة. سيطبع Wrangler رابطًا حقيقيًا بشكل `https://rivo-store.<your-subdomain>.workers.dev`. هذا هو الرابط الذي تستخدمه؛ لا تحتاج شراء دومين الآن. اسم Worker `rivo-store` يجب ألا يشير لمشروع آخر موجود عندك؛ إن كان مستخدمًا لموقع مختلف غيّر `name` في wrangler.json قبل النشر.

### 5. إنشاء حسابك وتعيينه أدمن

1. افتح رابط الموقع ثم `/register` وسجّل حسابك بنفسك. احفظ رمز الاسترداد.
2. بنفس المتصفح وأنت داخل حسابك، افتح `/api/session` وانسخ قيمة `user.id`. لا تستخدم معرف حساب شخص آخر ولا تعتمد على تشابه الإيميل.
3. في PowerShell بدّل `YOUR_USER_ID` بالمعرّف الذي ظهر لحسابك:

```powershell
npx wrangler d1 execute DB --remote --command "UPDATE auth_accounts SET role='admin' WHERE user_id='YOUR_USER_ID';"
```

4. ارجع إلى `/login` أو `/admin`. الصلاحية تُقرأ من قاعدة البيانات بكل طلب، ولا تحتاج تغيير الإيميل أو إعادة النشر.
5. أضف رقم واتساب، المنتجات وإعدادات المتجر.

للرجوع إلى صلاحية زبون، نفّذ الأمر نفسه مع `role='customer'`.

## تشغيل محلي

```powershell
npm run db:local
npm run dev
```

استخدم رابط localhost الذي يطبعه Wrangler. المتصفح يحتاج قبول Secure cookies على localhost. الاختبارات الآلية لا تتصل بقاعدة الإنتاج ولا تحتاج حساب Cloudflare.

## بنية الملفات

- worker.mjs: توجيه الطلبات وCron التنظيف.
- lib/auth.mjs: الحسابات، الجلسات، الاسترداد وتحديد المحاولات.
- lib/store-api.mjs: إدارة المتجر والطلبات وصلاحياتها.
- public/: الواجهة الأصلية وصفحات الحساب والثيم والأصول.
- migrations/: جداول المتجر والحسابات. أضف ملفات جديدة للتعديلات المستقبلية؛ لا تعدّل ترحيلًا طُبّق سابقًا.
- tests/: اختبارات الحسابات وصلاحيات المتجر وأسعار الطلبات.

## التحقق

15 اختبارًا آليًا نجحت، وتجميع Wrangler dry-run نجح. لا يغني ذلك عن تجربة النشر الفعلي في حسابك، ولا يشمل اختبار بوابة دفع أو مزود إيميل غير مربوطين. مراجعة المتصفح المرئية لم تُنفّذ لهذه النسخة المستقلة.
